# Инструменты разработки

`balance.py`: проверка баланса. Берёт продукты и рецепты из `scripts/data.gd`, прогоняет все подносы от 1 до 3 блюд через ту же физику полёта, что в игре, и пишет `balance.md` (отчёт) и `balance.csv` (вся таблица).

    python3 balance.py                         # текущая игра, отчёт рядом со скриптом
    python3 balance.py <папка проекта> <куда>   # другой data.gd, например черновик нового ларька

Если меняется физика в `scripts/main.gd` (тяга, булки, рывок, сопротивление), те же числа нужно поменять в начале `balance.py`.

`upgrades.py`: прокачка за талоны. Прогоняет пять подносов с ремнём и рубашкой-парашютом уровней 0–3 и печатает высоту, время в воздухе и дальность. Цифры прокачки в начале скрипта те же, что `UPGRADES` в `scripts/perks.gd`.

    python3 upgrades.py

`daily_test.gd`: условия испытания дня на 30 дней вперёд (цель, поднос, 4 продукта и блюда из них) и сколько раз выпала каждая цель. Падает, если в какой-то день готовится меньше 3 блюд. Копируется в проект и запускается как `sky_shot.gd`:

    godot --headless --path ../turbo-vorotnichok -s tools_test/daily_test.gd

`perf_test.gd`: нагрузка. Длинный полёт на трёх бизнес-ланчах с булками; печатает время кадра, вызовы отрисовки, число узлов и облачков газа. Запуск как `daily_test.gd` (с `--headless` время только логики, через `xvfb-run` вместе с отрисовкой).

`rcedit-shim/`: замена rcedit для экспорта exe на Linux, ставит свой значок и версию. Как подключить, написано в README проекта, раздел «Версия для Windows».
