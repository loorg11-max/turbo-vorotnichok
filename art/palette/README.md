# Палитра Turbo32

32 цвета, сняты с референса из GPT и дополнены ключевыми цветами героя.

- **Обводка и тени:** `#090c1c`, `#1a1623`, `#2b2638`
- **Вечерний город:** `#22385c`, `#28497e`, `#41577f`, `#587c9d`, `#6d82ac`
- **Небо:** `#2d81da`, `#4e9ff5`, `#95b9e3`, `#d6e8f7`
- **Рубашка и свет:** `#f7f4ea`, `#ede6bc`, `#c9ccd6`
- **Кожа:** `#e9cdb3`, `#d8a07a`, `#a67e66`
- **Волосы:** `#7a4a2a`, `#4a2a1c`
- **Галстук и вывеска:** `#e8342a`, `#c91410`, `#690f0e`, `#561c26`
- **Газ:** `#d0ed4e`, `#a2d576`, `#7ec26b`, `#3f7a3a`
- **Неон:** `#ffd84a`, `#f59a23`
- **Асфальт и металл:** `#bcb6ad`, `#544f4f`

Файлы: `turbo32.png` (по точке на цвет, для загрузки в PixelLab или Retro Diffusion), `turbo32.gpl` (Aseprite: Palette → Load), `turbo32.hex` (Lospec), `turbo32-preview.png` (посмотреть глазами).

## turbo-full (57 цветов)

Основная палитра для картинок из GPT: Turbo32 плюс оттенки с выбранного референса. Строгих 32 цветов не хватало, картинки после чистки выглядели грязно. Файл `turbo-full.hex`.
