# Турбо белый воротничок

Инди-игра в духе «Алхимии»: офисный работник Геннадий смешивает еду в уличных ларьках, чтобы от газов улететь как можно выше и дальше. Godot 4.3, GDScript, пиксель-арт 640×360.

## Что где

| Папка | Что внутри |
|---|---|
| `godot/turbo-vorotnichok/` | Проект Godot: сцены, скрипты, картинки, звуки, шрифты. Подробности и проверка снимками в его `README.md` |
| `godot/tools/` | Проверки и расчёты: баланс рецептов, прокачка, испытание дня, геймпад, нагрузка, замена rcedit для значка exe |
| `godot/design/` | Описания: Пышечная, талоны и задания |
| `art/gpt/` | Картинки из GPT: исходники в `raw/`, промпты, `build.sh` сводит их к сетке и палитре и кладёт в проект Godot |
| `art/tools/` | Скрипты пиксель-арта: `pixelize.py`, `split_sheet.py`, `small_sprite.py`, сборка героя |
| `art/palette/` | Палитра игры, 57 цветов |
| `audio/tools/` | Звуки и музыка, сделанные кодом |

Готовых сборок (zip для Windows) здесь нет, они лежат в папке проекта Claude: `godot/builds/`.

## Как запустить

1. Установить Godot 4.3 (обычная версия, не .NET).
2. Открыть `godot/turbo-vorotnichok/project.godot` и нажать F5.

Сборка для Windows: шаблоны экспорта Godot 4.3, затем «Проект → Экспорт → Windows».
